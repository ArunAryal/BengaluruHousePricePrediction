# Bengaluru House Price Predictor

A small machine-learning project that estimates the price of a flat or house in Bengaluru from its location, size and number of rooms. A scikit-learn regression pipeline is trained in a Jupyter notebook, saved with `joblib`, and served through a [Streamlit](https://streamlit.io) web app.

- **Live app:** [arunaryal-bengaluruhousepriceprediction-app-koc5xi.streamlit.app](https://arunaryal-bengaluruhousepriceprediction-app-koc5xi.streamlit.app/)
- **Inputs:** location, total area (sqft), bedrooms (BHK), bathrooms
- **Output:** estimated price (shown in lakh) and the implied price per sqft
- **Best test R²:** about 0.85

> Estimates are indicative only. The data is listing prices, and factors such as builder, floor, age and amenities are not in the model.

## Run it locally

You need [uv](https://docs.astral.sh/uv/) and Python 3.11 or newer.

```bash
git clone https://github.com/ArunAryal/BengaluruHousePricePrediction

uv sync                      # creates .venv and installs the locked dependencies
uv run streamlit run app.py  # opens the app at http://localhost:8501
```

The app loads `house_price_model.joblib` from the project folder. To use a model stored elsewhere, set the `HOUSE_MODEL_PATH` environment variable:

```bash
HOUSE_MODEL_PATH=/path/to/model.joblib uv run streamlit run app.py
```

If the model file is missing, the app shows an error message instead of crashing.

> **scikit-learn version:** the saved model was trained with scikit-learn 1.9, and `pyproject.toml` pins `scikit-learn==1.9.*`. A pipeline saved with one scikit-learn version can fail to load, or predict wrongly, under another, so keep the pin in step with the version used for training.

## How it works

### Data

`Bengaluru_House_Data.csv` holds 13,320 Bengaluru listings with 9 columns: area type, availability, location, size, society, total area, bathrooms, balcony and price (in lakhs; 1 lakh = ₹100,000).

### Cleaning (`HousePricePrediction.ipynb`)

1. Dropped `society` (41% missing), `area_type`, `balcony` and `availability`, which are redundant with other columns or only weakly correlated with price.
2. Extracted the number of bedrooms (`bhk`) from the free-text `size` column ("2 BHK", "4 Bedroom", ...).
3. Converted `total_sqft` ranges such as "1133 - 1384" to their midpoint.
4. Filled missing `bath` and `bhk` values with medians grouped by the correlated column.
5. Grouped locations with 10 or fewer listings into a single `other` category.
6. Removed outliers: homes under 300 sqft per bedroom, per-location price-per-sqft outliers (outside one standard deviation of the location mean), and N-bedroom listings priced per sqft below the average for (N−1)-bedroom homes in the same location (when that group has more than 5 listings).

This leaves 7,360 rows and the columns `location`, `total_sqft`, `bath`, `bhk` and `price`.

### Model

A scikit-learn `Pipeline` with two steps:

- **Preprocessing:** one-hot encoding of `location`; standard scaling of `total_sqft`, `bath` and `bhk`.
- **Regressor:** linear regression, tried alongside Lasso and Ridge.

The data was split 80/20 (5,888 training and 1,472 test rows, `random_state=0`).

| Model | Test R² |
|---|---|
| Linear Regression | 0.854 |
| Ridge (default `alpha`) | 0.852 |
| Lasso (default `alpha`) | 0.708 |

Linear Regression and Ridge are effectively tied. Lasso scores lower with its default settings. Neither Lasso nor Ridge has been tuned.

The app uses the **Ridge** pipeline, saved as `house_price_model.joblib`.

```bash
uv run --with jupyterlab jupyter lab
```


- Cell 5 builds an optional data-profiling report (`DataAnalysis.html`) and needs the `ydata-profiling` package. The report is not needed for the model, so you can skip that cell.
- `Cleaned_data.csv` and `DataAnalysis.html` are generated by the notebook and are not tracked in git.

## Limitations

- **Linear model:** it can return a zero or negative price for very small areas with many rooms. The app shows a warning instead of a price in that case, and it also warns about cramped layouts (under 300 sqft per bedroom) and unusually many bathrooms.
- **Rare areas:** locations with 10 or fewer listings share the `other` category, so estimates there are less precise.
- **Optimistic test score:** outlier removal and the rare-location grouping were computed on the full dataset before the train/test split, so the reported R² is likely a little optimistic.
- **Listing prices:** the target is the asking price, not the final sale price.
